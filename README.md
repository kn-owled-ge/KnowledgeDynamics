# Knowledge dynamics — structural-model research code

Historical MATLAB research code for a structural model of knowledge dynamics. The repository includes model solution, simulation, calibration and analysis routines, together with supporting data and numerical artifacts.

## Orientation

- `Run.m` contains an original run configuration and parameter vector.
- `mainF.m`, `modelF.m`, `vfiCC.m` and `simCC.m` provide entry points into the model and numerical workflow.
- The related [StataProgs](https://github.com/kn-owled-ge/StataProgs) repository contains data preparation code for this project.

This is a 2016 research snapshot. Local paths, data inputs, MATLAB dependencies, cluster scripts and included compiled binaries reflect its original execution environment. Review those requirements before running the code. This documentation update does not establish an end-to-end replication procedure or correspondence to a specific later manuscript version.
